Пет-проект на Python, анализирующий доступность покупки жилья в Санкт-Петербурге в период с 2013 года, используя открытые данные портала bn.ru и других источников. 
Проект сопоставляет динамику зарплат, ставок по ипотеке, цен на недвижимость и рынка аренды, чтобы ответить на вопрос: выгоднее ли сейчас покупать жильё в ипотеку или лучше ее снимать и инвестировать разницу?

Калькулятор:
- считает ежемесячный аннуитетный платёж по ипотеке для заданного периода и параметров;
- вычисляет рентную доходность (rental yield) — сколько условно приносит недвижимость, если сдавать её в аренду, относительно её стоимости;
- сравнивает рентную доходность с альтернативными доходностями — дивидендной доходностью индекса мосбиржи;
- показывает, как соотношение «зарплата / стоимость жилья» менялось год к году с 2013 года.

Цель проекта:
Это учебный проект, для для дальнейшего развития моих навыков в Python. Помимо практики программирования, 
он служит инструментом для собственного финансового анализа рынка недвижимости и его сопоставлении с альтернативными инструментами.
